# Maya Agent Hub

A lightweight local control center for running and supervising small automation agents.

The hub coordinates scheduled research and monitoring jobs, stores their latest results and exposes a compact web dashboard.

## Highlights

- Multi-agent scheduling
- Local SQLite-backed result storage
- Health and status reporting
- Web dashboard
- Pluggable agent configuration
- Local-network-first design

## Privacy

Personal profiles, live databases and machine-specific configuration are intentionally not included. Use config.example.json as a starting point.

## Stack

Python, SQLite, JavaScript, HTML, CSS.
